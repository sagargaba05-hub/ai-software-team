# Contributor Covenant Code of Conduct

## Our Pledge

We are dedicated to fostering an inclusive, respectful, and welcoming environment for all participants. We pledge to treat everyone with dignity and respect, and to create a safe space for collaboration.

## Our Standards

All participants are expected to:

- Treat others with respect and courtesy.
- Avoid harassment, hate speech, or any form of discrimination.
- Be mindful of language and tone.
- Provide constructive feedback.

## Enforcement

Violations of this code will be addressed promptly. If you witness or experience misconduct, please report it to the project maintainers.
