# Runbook

## Continue startup

1. Open one target folder with **File > Open Folder** in VS Code.
2. Reload the VS Code window after changing the global Continue configuration.
3. Select `OmniRoute AI Team Auto` and Agent mode.
4. Ask “Which workspace are you connected to?” The response must come from `ai_team_workspace` and match the open folder.
5. Ask the agent to find a known file and run a harmless check such as the repository's test command.

If tools do not appear, inspect Continue's MCP status and restart only the `AI Software Team` MCP server. If model replies fail, verify OmniRoute on `127.0.0.1:20128` and Ollama on `127.0.0.1:11434`.

The MCP subprocess timeout defaults to 14,400 seconds. Override it only with a process-level `MCP_TIMEOUT_SECONDS` integer from 1 through 86,400; the MCP server never reads this value from the target project's `.env`.

## Resume and release evidence

`resume` continues from the persisted `pending_stage`. Inspect `.ai-team/state.json` when diagnosing an interruption: schema version 3 retains append-only `stage_results` and per-finding `repair_cycles`. A migrated schema-v2 run may continue, but any missing current-run evidence remains a release blocker and must be regenerated by the relevant stage.

Final Gate is code-owned. A model response containing `STATUS: PASS` cannot approve release unless each applicable check has a matching structured result for the current `run_id`.

## GitHub

Use `ai_team_github_status` to confirm the authenticated `gh` account and the current repository origin. Correct an incorrect origin deliberately before any write. The automatic tool does not commit or push.

## Project memory

Use `ai_team_context` to inspect durable facts and `ai_team_remember` only when the user explicitly provides a stable non-secret fact. Source code remains authoritative for implementation details.
